# G1 23DoF IsaacLab training recipe

本文记录 G1 23DoF 行走与上肢扰动控制的训练配置，完整运行25001次PPO更新；评估证据见[评测结果](RESULTS.md)。

## 2. 本体与控制划分

23个活动关节全部保留。PPO控制左腿6、右腿6、腰yaw1，共13维；左右臂各5维由独立的`UpperBodyPoseAction`驱动，该term消耗0维策略动作。腰属于策略动作，不是随机上肢扰动。

关节位置/速度观测严格按上游深度优先语义顺序排列；PhysX内部广度优先索引用名称映射，不能直接取前13个物理关节。策略目标为`q_default + scale_j × action_j − encoder_bias_j`；手臂是绝对位置轨迹目标。随机手臂目标通过限速/限加速度轨迹连接，每个环境异步更新，允许一侧臂静止。

`UpperBodyPoseAction.set_external_target()`保留外部10维关节目标接口，后续可接遥操作或VLA产生的关节目标。本次未连接DDS、未发送真机命令，遥操作IK仍属于上层控制，不放进训练循环。

## 4. 命令与课程

命令每3–8秒重采样。heading=True，目标朝向随机；yaw命令=clip(0.5×wrap(目标−实际朝向), yaw范围)。没有额外独立纯横移/纯转向配额，不恢复此前已撤销的分类采样。

| 阶段起点（PPO轮数） | vx | vy | yaw |
|---|---|---|---|
| 0 | [−0.3,0.6] | ±0.2 | ±0.4 |
| 1500 | [−0.5,1.0] | ±0.4 | ±0.8 |
| 3500 | [−0.75,1.0] | ±0.45 | ±0.9 |
| 5000 | [−1.0,1.0] | ±0.5 | ±1.0 |

每次速度范围转换在500轮内渐变，并非一次跳变；本轮仍按上游步数课程，不私自改成reward阈值课程。课程执行在reset时，部分条件为严格大于，表中阶段数字不是保证所有环境在该轮瞬时切换。

| 高度下界课程轮次 | 0 | 1500 | 3000 | 5000 | 6000及以后 |
|---|---:|---:|---:|---:|---:|
| 静止/下蹲高度下界m | 0.68 | 0.68 | 0.60 | 0.38 | 0.24 |

高度上界/名义站立高度始终0.78m；运动时另设最低高度0.71→0.71→0.68→0.64→0.60m，对应0/1500/3000/5000/7000轮。站立命令概率20%→25%→30%，名义高度采样占比50%逐渐降到10%。高度移动判据是三维twist的L2范数>0.1，不完全等同于奖励里的`norm(vxy)+abs(yaw)`。

手臂工作空间/动态课程比例在0、1500、3000、5000、7000轮分别为0.15、0.15、0.50、0.75、1.0。轻扰动环境占比50%逐步降到10%，轻扰动比例上限0.1。r=0时的目标关节速度插值端点范围0.2–0.8rad/s，最终0.3–3.5；加速度r=0插值端点0.5–3，最终1–20rad/s²，按课程插值。轨迹算法沿用源实现，包括近目标截断行为，不能把这些采样上限当作真机执行器的硬限速保证。

推扰按0/1000/3000/5000轮，从最终幅度的10%/30%/65%/100%渐增；每3–5秒一次。每手附加质量0.25–1.75kg，躯干−0.5–2kg，reset时采样；保持上游body_mass语义，质量变化不同比例缩放惯量。脚摩擦、躯干/手部COM、编码器偏差同时保留。

**上游版本差异**：README与附带model_15500/deploy_contract描述的是较早策略，不能代表当前训练源码。当前源码高度范围是[0.24,0.78]，本迁移以该commit实际配置为准；不加载其原生mjlab checkpoint继续训练。

## 5. 全部22项奖励

所有权重由IsaacLab reward manager再乘控制dt=0.02。没有额外加入旧迁移版的`stand_turn_lin_vel_penalty`；现有的`idle_base_motion`和`idle_position_anchor`按分轴命令门控也会约束原地转向的平移。

| 奖励 | 权重 | 含义 |
|---|---:|---|
| track_linear_velocity | 1.5 | 机体系xy速度误差与2倍竖直速度平方，exp(−error/0.25) |
| track_angular_velocity | 1.75 | yaw误差与0.05倍roll/pitch角速度平方，exp(−error/0.5) |
| track_base_height | 2 | pelvis相对较低足部参考点高度，加0.02m修正，exp(−4×绝对误差) |
| body_orientation_l2 | -2.5 | 躯干倾斜；深蹲时由全权重降到30% |
| body_ang_vel | -0.05 | 躯干世界系roll/pitch角速度平方 |
| pose | 1 | 13个受控关节的默认姿态指数奖励；按运动强度与下蹲高度切换容差 |
| feet_distance | -0.75 | 双脚机体系横向间距超出0.20–0.35m的距离 |
| idle_base_motion | -1 | 平移命令近零时惩罚vxy²，yaw命令近零时惩罚0.5×wz²，分轴门控 |
| idle_position_anchor | -5 | 停止时锁定xy/yaw参考，2.5cm/0.02rad死区外惩罚位移；推扰后重新锁定 |
| com_support | -1 | 双支撑时全身质量加权CoM超出保守足间椭圆的成本，运动时乘0.25 |
| idle_feet_still | -0.25 | 静止命令下足部水平运动与腾空惩罚 |
| foot_gait | 0.5 | 0.6秒周期、左右相差0.5、支撑阈值0.56，接触相位平均匹配 |
| foot_clearance | -1 | |足点高度−0.1|×水平足速；运动命令才启用 |
| foot_slip | -0.25 | 着地足的水平速度平方；站立也启用 |
| feet_air_time | 0.05 | 单支撑状态持续时间接近0.4秒的奖励 |
| is_terminated | -200 | 非超时终止 |
| self_collisions | -0.25 | 超过50N的自碰撞历史计数；PhysX采用各link过滤合力近似 |
| joint_pos_limits | -10 | 全部23关节软限位越界 |
| action_rate_l2 | -0.1 | 13维策略动作一阶差分平方 |
| action_smoothness_l2 | -0.02 | 13维动作二阶差分平方 |
| joint_vel_l2 | -0.0001 | 13个受控关节角速度平方 |
| joint_acc_l2 | -2.5e-07 | 全部23关节角加速度平方，沿用源配置 |


普通环境从r=0.15开始，实际初始速度范围0.215–1.205rad/s，加速度0.575–5.55rad/s²。

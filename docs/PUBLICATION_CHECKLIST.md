# Publication steps

The [source repository](https://github.com/yezheng04/unitree-g1-23dof-decoupled-control) is public. The evaluated model and full videos are distributed in the [checkpoint 22000 release](https://github.com/yezheng04/unitree-g1-23dof-decoupled-control/releases/tag/v0.1.0-22000). The steps below describe the publication workflow for future updates.

1. Create your own GitHub repository, choosing visibility and name.
2. Review README wording and upstream attribution. Add your preferred author/profile link if desired.
3. From this prepared directory, create the first commit with your Git identity and add your GitHub remote.
4. Push source only. Keep assets/, artifacts/, logs/, outputs/ and credentials ignored.
5. Upload the separate artifact archive to a Release; add that actual download URL to the README.

No account password, API key, private IP, shell history or original Git history is included in the source export. The packaged recipe and quantitative results still require the documented GPU/software environment to reproduce.
